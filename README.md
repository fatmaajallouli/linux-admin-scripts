# Linux Admin Scripts

A collection of interactive Bash scripts for Linux system administration, written as part of my software engineering studies.

## Scripts

### adminuser — User account management

An interactive menu to explore the user accounts on a Linux system.

**Features:**
- List all user accounts
- Count the number of accounts
- Show information about the current user
- Search for a specific user

**Linux commands used:** `cat`, `wc`, `grep`, `whoami`, `read`, `case`

**Usage:**
```bash
chmod +x adminuser
./adminuser
```
